# our-taskdepot

our-taskdepot は、C言語を学び始めた人が、コンパイルエラーを読んで自分で直せるようになるための Windows アプリです。

## どんなときに使う？

C言語の課題や練習問題でコードを書いたあと、英文のエラーメッセージだけでは原因が分からないときに使うことを想定しています。

公開版では、`.c` ファイルを開くか、入力欄にコードを書いたり貼り付けたりしてコンパイルできる予定です。エラーが出た場所、メッセージの意味、考えられる原因を日本語で確認できます。

## 入手方法

現在は開発中で、利用者向けの配布版はまだ公開していません。コンパイル処理は実装済みで、操作画面と日本語のエラー解説は開発予定です。

- 対応予定の環境は Windows 11（x64）です。
- 配布版の公開状況は [GitHub Releases](https://github.com/nek0m0dok1/our-taskdepot/releases) で確認できます。
