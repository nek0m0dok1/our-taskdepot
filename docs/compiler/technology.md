# 技術選定と理由

更新日：2026-11-04。状態：合意済み設計・具体的リリース等は未検証。対象：コンパイル環境。

| 項目 | 決定と理由 |
|---|---|
| OS | Windows 11 x64。既存の対象環境を維持する |
| アプリ本体 | C・MSVC。既存の開発基盤を維持する |
| 利用者コード | LLVM-MinGW（UCRT）を同梱。別途導入を不要にし、バージョンと診断の一貫性を管理する |
| 起動 | Windows API。Unicodeパスの扱いは[プロセス制御](process.md)参照 |
| ビルド・テスト | CMake・CTest。既存構成に統合する |

アプリ本体のビルドと利用者コードのコンパイルは目的が異なるため、同じコンパイラに統一しない。本書のC23は利用者コードに適用する規格である。

## コンパイル条件

- `-std=c23`：新しいC言語規格を学べるようにする。
- `-Wall`・`-Wextra`：主要な警告と追加警告を有効にする。
- 出力はWindows実行ファイル。その他の必要な生成オプションは実機動作を確認し、実装時に再現可能な形で固定する。

初期版ではGUIにも呼び出し側にも任意オプションを公開しない。同じコードの診断条件を統一し、設定項目とテストの負担を抑えるためである。自由な設定は将来の拡張候補とする。

## 同梱に伴う確認

C23指定だけでは全機能の実装を保証しない。Clangの具体的バージョンと必要なC23機能の対応を検証して固定する。同梱配置・依存ファイル・配布容量・各構成要素のライセンスと再配布条件も確認する。必要な構成を調査しても動作を損なわないこと。

既存の選定根拠は[ADR-0003](https://github.com/nek0m0dok1/our-taskdepot/blob/main/docs/adr/0003-compiler-integration-policy.md)。検証の残件は[未検証事項](decisions.md)参照。
