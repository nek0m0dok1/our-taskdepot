# ADR-0001：GUI技術の選定

**ステータス：採用候補（動作検証待ち）**

## 背景

本プロジェクトでは、Windows向けのC言語エラー解説ツールを開発する。

GUIには、ソースコードの入力・編集、ファイル選択、コンパイル操作、エラー解説の表示が必要となる。

開発言語はC言語とし、外部ライブラリの利用は認められている。

## 検討した選択肢

- Win32 API単体
- Win32 API + Scintilla
- GTK 4 + GtkSourceView

## 採用候補

Win32 API + Scintilla

GUI全体をWin32 APIで構築し、コード編集部分にScintillaを使用する。

## 理由

- Windows向けアプリケーションという要件に適している。
- Scintillaによってコード編集機能の実装負担を軽減できる。
- 行番号やシンタックスハイライトなどの機能を追加しやすい。
- GUIとエラー解析などの内部処理を分離して開発できる。

## 懸念点

- Win32 APIとScintillaの両方を学習する必要がある。
- Scintillaの組み込みと依存ファイルの管理が必要となる。
- GUI担当者に作業が集中する可能性がある。

## 採用条件

- C言語からScintillaを操作できることを確認する。
- 学校のWindows環境でビルド・実行できることを確認する。
- チーム内で共通の開発環境を再現できることを確認する。

上記を検証した後、正式採用とする。
