# ADR-0002：ビルドシステムの選定

**ステータス：採用方針（動作検証待ち）**

## 背景

開発メンバーが使用するIDEやエディタに依存せず、共通の手順でアプリケーションをビルドできるようにしたい。

また、GUIライブラリや複数のソースファイルを扱うため、ビルド設定を一元管理する必要がある。

## 決定方針

ビルドシステムにCMakeを採用する。

ソースファイル、ライブラリ、ビルドオプションなどの設定をCMakeLists.txtで管理し、Gitで共有する。

## 理由

- Visual StudioやVS Codeなど、使用するIDEを限定しない。
- ターミナルからビルドできる。
- メンバー間でビルド設定を共有できる。
- ソースファイルや依存ライブラリが増えた場合も管理しやすい。

## 注意点

CMake自体はコンパイラではないため、別途C言語のコンパイラが必要となる。

また、CMakeを導入しても、使用するコンパイラや必要なSDKなどの環境構築が不要になるわけではない。

## 未決定事項

- 開発用コンパイラ
- CMakeジェネレーター
- Scintillaの組み込み方法

これらは開発環境の検証を通して決定する。
