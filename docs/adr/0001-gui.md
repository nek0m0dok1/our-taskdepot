# ADR-0001：GUI技術の選定

**ステータス：採用決定**  
**決定日：2026年10月26日**

## 背景

本プロジェクトでは、Windows向けのC言語エラー解説ツールを開発する。

GUIには、ソースコードの入力・編集、ファイル選択、コンパイル操作、エラー解説の表示が必要となる。

開発言語はC言語とし、外部ライブラリの利用は認められている。

## 検討した選択肢

- Win32 API単体
- Win32 API + Scintilla
- GTK 4 + GtkSourceView

## 決定

GUIにはWin32 API、コード編集部分にはScintillaを採用する。

Scintillaはビルド済みDLLを使用し、必要なファイルをプロジェクト内で管理する。

## 決定理由

- Windows向けアプリケーションという要件に適している。
- Scintillaによってコード編集機能の実装負担を軽減できる。
- 行番号やシンタックスハイライトなどの機能を追加しやすい。
- GUIとエラー解析などの内部処理を分離して開発できる。
- ビルド済みDLLを使用することで、各メンバーがScintillaを個別にビルドする必要がなくなる。

## 懸念点と対応

### 学習コスト

Win32 APIとScintillaの学習が必要となる。

これらの学習と初期実装は、開発環境の整備担当者が中心となって対応する。

### 依存関係

ScintillaのDLLやヘッダーファイルなどの管理が必要となる。

必要なファイルとビルド設定を共通化し、メンバーごとの設定作業を減らす。

### 作業の集中

GUIの初期実装や環境構築が特定のメンバーに集中する可能性がある。

GUIと内部処理をモジュール単位で分離し、ほかのメンバーが独立して開発できる構成を目指す。
