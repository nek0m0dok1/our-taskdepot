## GUIの手動確認（今後の画面実装後）

- [ ] アプリの画面が開く。
- [ ] 編集欄にCコードを入力できる。
- [ ] 日本語を入力・コピー・貼り付けできる。
- [ ] サイズ変更に編集欄が追従する。
- [ ] 閉じる操作で終了し、プロセスが残らない。

現在の基盤に製品画面はありません。上記は今後の画面実装後に確認し、今回のセットアップ成功条件には含めません。

## 共同作業の練習

- [ ] 各自が`main`から小さな作業ブランチを作る。
- [ ] ファイルを変更し、ビルドとテストを実行する。
- [ ] 差分を読み、変更内容の分かるコミットを作る。
- [ ] PRを作り、別のメンバーがレビューする。
- [ ] 指摘への修正と再確認を行う。
- [ ] リーダーがブランチ保護とレビュー条件を確認する。

## 失敗時に共有する情報

実行したコマンド、最初に出たエラー、環境確認の出力、ブランチとコミットを共有してください。
ユーザー名や個人フォルダー名を含む出力は必要に応じて伏せ、認証情報は貼り付けないでください。
